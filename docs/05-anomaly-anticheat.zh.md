# 05 — 异常检测与行为反作弊

> 英文版为主文档：[05-anomaly-anticheat.md](05-anomaly-anticheat.md)

> 同一套数据基础设施，两种用途：经济风控 + 行为反作弊。
> 铁律：**检测系统只标记，不处罚**。输出进复核队列，人来定罪。

## 1. 数据底座

Agent 采集（经玩家知情同意声明，接入即公示）：
- 行为流：移动轨迹（区块粒度采样，不做逐 tick）、点击/交互速率、挖掘/放置速率与方块类型
- 经济流：全量交易/挂单/转账（账本天然具备）；村民交易经 `merchant.trade` 汇入（docs/03 §10）
- 物流流：库存增量、流量计读数（04）

特征工程每日物化到 `player_features_daily`（离线批处理，不上实时链路）。

## 2. 分层检测

### L1 规则层（实时，规则表热更）
挖掘速率 > 理论上限 ×1.2（按工具/方块类型查表）、库存净增 > 合法来源上界（刷物品检测的粗筛）、
同 IP 多账号环转账、新号 T+0 大额转账。规则全部参数化 + 版本化（规则变更可审计，企业级✔）。

### L2 统计层（日批，每玩家自适应基线）
- 稳健统计：对每玩家每特征维护 **中位数 + MAD**（抗污染：外挂行为不会把基线带偏），robust z > 6 → 标记
- EWMA 漂移检测：行为模式突变（挂机脚本特征：方差趋零 + 活动周期 24h 无休息）
- 群体对照：同 cohort（游玩时长/租户）横向分位，前 0.1% 标记
- 非玩家雇员同样入基线：每村民 `merchant.trade` 产出喂给末位淘汰的输入，
  含 p95/p5 诚实检查（docs/07 §7）

### L3 模型层（周批，离线）
- 无监督：Isolation Forest / LOF（Java 侧 Smile 库或 Python sidecar，P3 起步）圈出离群簇 → 人工归因
- 图检测（经济专项）：
  - **对敲环**：转账图上的循环流（A→B→A 加噪），用环检测 + 金额守恒近似度打分
  - **刷单网络**：拍卖行自成交 → 买卖双方资金回流图
  - **市场操纵**：单账户（或关联簇）挂单量占订单簿深度 > 阈值且频繁撤单（spoofing 模式）

## 3. 经济审计的不变量（复式账本的免费午餐）

账本结构自动给出四条对账线（06 §5 展开实现）：
1. **Σ余额 ≡ 0**（借贷平衡；破 = 记账 bug 或绕过账本的刷钱）
2. **物品守恒**：Σ(来源产出 − 消耗 − 销毁) ≡ 当前存量（破 = dupe，误差定位到时间窗+玩家）
3. **faucet/sink 分录守恒**：每笔货币诞生必有 faucet 分录（破 = 直改数据库，已越权）
4. **铸币守恒**：计量内村民交易付币总量 ≤ 流量计喂入的理论上限（每 offer 汇率 ×
   交易锁定预算——上限由游戏机制写死，docs/03 §10；破 = 漏计的 feeder 或 Agent 少报）

不变量每日跑 reconciliation job，破坏即触发最高级别告警——**这是比任何模型都硬的检测**。

## 4. 公平性原则（写给未来的我们自己）

- 标记 ≠ 定罪：所有 L2/L3 输出进复核队列，附证据包（特征快照 + 相关分录），复核结论回流成标注数据反哺 L3
- 可解释：每个标记必须能给人讲明白"为什么"（特征贡献列表），黑盒分数不能作为证据
- 申诉通道 + 检测规则对玩家公开（服主可选隐藏 L3 细节防对抗，但 L1 规则公开）
- 对抗演化：检测特征集版本化，重大版本切换后前 2 周只观察不标记（防止误伤潮）

## 5. 阶段

P1：数据采集 + L1 规则表 + 复核队列（人工看板）  
P2：L2 稳健基线 + 经济不变量对账 job  
P3：L3 无监督 + 图检测
