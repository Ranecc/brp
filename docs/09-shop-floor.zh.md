# 09 — 车间与区块治理（P2）

P2 让 BRP 从监控系统变成操作系统：Minecraft 的 WMS/MES/APS。玩家拿到
实体终端而不是网页表单；Web 只做控制台。区块加载变成可计量、可计费、
可远程开关的公共事业。休闲玩家不需要金融学位也能起家。

从 P0/P1 继承的设计铁律：文案可以审判你，状态机不行（AGENTS.md 梗边界）。

## 1. 终端三件套

命名原则：方块 ID 保持无聊且直白（ID 是管道，不是段子）；个性只存在于
lang/tooltip 里。需要脚注才能看懂的名字没通过 code review。

| 方块（id） | 中文 | 职责 |
|---|---|---|
| **Dispatch Terminal**（`brp:dispatch_terminal`） | 调度终端 | 收发令的 HMI：工单收发、信号下达与回执、各产线状态一目了然。「收发令」该干的事它都干，且全程留痕。 |
| **Line Controller**（`brp:line_controller`） | 产线控制器 | 链路编排执行器：持有产线程序（有序步骤，每步带条件——能量、配额、价格窗口、时间），强制条件开机与产线级速率上限。原生红石农场以计量产线接入；模组产线经适配器接入。 |
| **Form Terminal**（`brp:form_terminal`） | 表单终端 | 游戏内表单亭：列出本租户待办表单，用原生 Minecraft 界面（`AbstractContainerMenu` + `Screen`，原版控件——不自研 GUI 框架，不嵌网页）逐张填写。玩家在游戏里填公文的唯一入口。 |

三者都是无租户属性的硬件：放置时绑定所在区块的租户，在治理判定不合格
的区块里拒绝履职（见第 4 节）。

## 2. 表单策略：表单是最后手段

- Web 控制台能自动推进的表单全部自动推进：上下文预填、政策允许处自动
  提交、其余一键批准。
- 只有人工决策真正必要时玩家才会见到表单（超阈值审批、货币登记变更、
  重定锚投票）。
- 必须填时：表单终端 → 选表单 → 原生 MC UI → 走和 Web 完全相同的 REST
  端点与幂等键。一套 API，两张脸。
- 目标是玩家无感：自动化把纸面工作从玩家身边推开，推给机器和腐竹的
  控制台。

## 3. 区块治理（区块管理）

区块加载就是服务器算力；算力要计量、要计费。

- **受管区块**：租户登记区块槽位（配额资源 `chunk_ticket`，V8 注释里
  早已预留）。登记按（租户，维度，区块）幂等。
- **计量**：agent 按分钟桶上报每区块 `chunk.load.minutes`；后端即时燃烧
  预付信用（行级锁；信用可为负——负债可见，绝不藏账）。
- **计费（预付费）**：租户**购买**区块加载分钟（`purchase` 端点）：
  `treasury` CREDIT → `chunk-sink`（SYSTEM_SINK）DEBIT，走账本同事务幂等；
  V12 在同一事务单元里守护分钟数发放——钱只扣一次，分钟只发一次。信用
  归零 → HALT + 一次通知。单价由腐竹配置（`brp.chunk.billing.cents-per-minute`，
  默认 0 = 免费算力，即开发模式）。只收整数分；浮点数进钱路是开除级事故。
- **管理者远程开关**：腐竹/官员可在控制台 DISABLE 受管区块；治理器必须
  在一个上报周期内停下该区块内 BRP 掌控的活动。移动、交互、渲染永远
  不碰——我们治理机器，不治理玩家。
- **野加载**（未登记区块里的第三方区块加载器）：检测、按野加载费率计量、
  可归因则记到所属租户账上、通知管理员（沿用 NOTIFY 姿态）。BRP 不去拔
  别家模组的 ticket——那是人类的撬棍。
- **起家补贴**：每个租户**首个**登记槽位自带起家信用包（默认 1440 分钟，
  `brp.chunk.governor.starter-minutes`）——起家发的是信用，不是货币：
  账本永远不为入驻铸币。控制台可再充值。起家不需要找高利贷。

## 4. 治理器（决策表）

纯函数、agent 侧、单元测试覆盖；同一张表也由后端只读提供以保持一致：

| 输入 | 判决 |
|---|---|
| 区块未登记 / 信用耗尽 / 账单逾期 / 管理员已停用 | **HALT** —— BRP 机械（终端、产线控制器、BRP ticket）停工；玩家照常走路、挖矿、建造 |
| 已登记，信用低于宽限线 | **THROTTLE** —— 产线速率上限降到生存底线；调度终端告警 |
| 已登记，信用健康，管理员启用 | **RUN** |

HALT 永远不等于「区块卸载」：原版模拟、移动与交互照常。它的意思是
账本表态之前 BRP 不为你工作。机器罢工了，世界没有。

## 5. APS：产能平衡

- **产线速率上限**（docs/03 §9 的数量配额落到每条产线）：产线控制器
  拒绝超上限运行；超目标边际产出照旧触发累进征课。
- **公平份额调度**：全局算力紧张时，算力预算（quota-minute）按份额权重
  = 已付 + 授予信用，在租户间分配，绝不谈判。喂 Gini 征课的那份周快照
  （docs/03 §9）同时喂份额权重——一份快照，多方意见。
- **条件开机条件**：energy_available、quota_remaining、price_window
  （TPS 现价落在带内）、time_window。全部基于缓存的后端状态本地求值；
  HALT 判决凌驾一切。
