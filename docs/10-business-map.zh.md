# 10 — 业务版图补全：order-to-cash 与它细长的尾巴

> 英文版为主文档：[10-business-map.md](10-business-map.md)
>
> 现状：BRP 是一台生产侧 ERP。采购 → 仓储 → 计划 → 执行 → 记账全闭环，
> **唯独 order-to-cash 开着口**——MRP 引擎（P3）没有油箱。本文一次性了结
> 业务版图之争：什么以薄模块发布、什么以一个字段发布、什么明确不做。
> 这是"这个 ERP 还缺啥"的常设答案，欢迎引用，拒绝再审。

## 1. 需求侧的三条轨道

服务器上的玩家，钱的事只有三种：

1. **公会间交易** ——租户对租户的 B2B
2. **玩家集市** ——地摊与拍卖行，玩家对玩家
3. **向服务器购买** ——系统商店（已在账本侧，03 稿）

三条轨道全部用同一种登记货币、走账本账户轨结算（03 §1）：玩家持有和交易
的是腐竹起的展示名，没人需要知道背后那一列的列值。轨道本身现成，缺的是
**没有任何东西把需求变成工单**。下面的骨架就是来补这一口的。

## 2. 三个薄模块（新-build 的全部）

| 模块 | 现实 ERP 对应物 | 在这里实际是什么 | 落点 |
|---|---|---|---|
| **销售订单** | SD / order-to-cash | 报价 → 订单 → WMS 履约 → 发货 → 发票 → 应收；P3 的 MRP 从订单展开工单，而不是从服主的心情展开 | P3 |
| **协议** | CLM 坍缩态 | 周期性供货协议（"每周 64 锭，押金在身"）= 账本上的条件划转——ESCROW、Saga、审批迷宫全都现成；这是一条释放规则，不是一个生命周期套件 | P3 |
| **工程项目** | PS + RE 坍缩态 | 工程：里程碑 = 09 稿任务板（WBS），预算 vs 实际 = 账本，验收 → 资产台账（基地/铁路/大厅/铁傀儡） | P4 |

只有销售订单是 MRP 真正离不开的。

## 3. 信用——公会尺度的"CRM"

没有漏斗、没有线索、没有营销。公会层只保留：

- **交易对手画像**：每个租户的价格史、履约记录
- **赊销额度 + 应收账龄**：玩家间赊账让违约风险真实存在——买家退服，应收
  变核销；托管裁决走审批队列
- 流失分析**只属于平台租户**（05 稿早就在采 `player.left`/`playedMinutes`；
  "连续 N 天未登录"是异常检测底座的一个特征，不是一个模块）

值得一提的后果：03 稿的危机表因此白得一路应收信号；而"客户关系管理"
终于有了它在服务器里应有的含义——知道谁付款，谁永远下线。

## 4. 以字段发布、而非以模块发布的系统

每一个都按现实 ERP 候选审过、按模块身份否决。残核所在如下；**否决本身就是
规格的一部分**，未来的范围之争请直接引用本表：

| 候选 | 裁决 | 残核去处 |
|---|---|---|
| PLM | 砍 | 配方由游戏写死；农场改版 = MRP 配方上一个 **BOM 版本字段**（P3 schema） |
| QM | 砍 | WMS **入库差异单**（我那批铁锭里掺了三颗金粒，P2）；附魔/铁砧 RNG = 入库时的 NBT 定级规则，不是实验室 |
| PM / EAM | 砍 | P4 **宕机台账**（区块卸载 / 漏斗堵料 / 没人渲染）——OEE 从已采数据里白捡；备件就是普通 WMS 物料 |
| TMS / LE | 拆 | 建设侧 → 工程项目（§2）；仓间移动 → WMS **调拨单**（P2）；日常物流是玩家 + ME 管道，02 稿已整合 |
| 税引擎 | 并 | 03 §4 的 sink + §10 铸币费——服务器"税收"从来是货币政策，不是合规文书 |
| CRM 套件 | 拆 | §3 信用 + §2 协议；玩家生命周期 → 05 稿（平台租户） |
| CO（成本核算） | 字段 | **完工成本打到工单上**（料 + 机时），标准 vs 实际做成列——schema 现在就定，P4 报表白送；"模块"永不 |
| DMS / wiki | 不做 | 玩家有 wiki 模组；SOP 是红石，图纸是蓝图方块 |

## 5. 路线图增量

- P2：WMS += 入库差异 + 调拨单；铸币计量事件与适配器同批落地（03 §10）
- P3：MRP += **销售订单骨架**、完工成本字段、BOM 版本；协议/托管释放规则；
  铸币费引擎
- P4：APS += 宕机台账 + OEE；工程项目 + 资产台账
- P5：不变——只是交易所会发现订单簿里从此有了真订单

## 6. 一句话宪法

有 procure-to-pay 而无 order-to-cash 的 ERP，是一台焊在油罐车上的发动机：
一切都在转，哪都不去。骨架在 P3 交付；本文其余部分是对"再审一次"的保险。
